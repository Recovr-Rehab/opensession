# Bro

Say your last message again, plainly. One person talking to another.

- Cut the jargon, the acronyms and the hedging. If a term has to stay, say what
  it means in the same breath.
- Make it shorter than the original. Anything that was there to sound thorough
  goes.
- Keep every fact: numbers, file paths, names, decisions, and what is still
  unresolved. This is a rewrite, not a summary that quietly drops things.
- Lead with the part the reader has to act on.
- Do no new work. No tools, no checking, no edits. You are restating what you
  already said, not redoing it.

If the last message was already plain, say so in one line instead of padding it
out.
